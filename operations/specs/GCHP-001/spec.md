# GCHP-001 Specification — Interactive protected crypto operator

## Purpose

Deliver a usable Hermes profile paired with GC-001 that can inspect the gateway, configure human-authorized portfolio controls, submit strict protected decisions, and reason about edge and management without credentials or direct execution authority.

## Requirements

- Provide SOUL and focused skills for market judgment, strict intent construction, position management, and learning.
- Provide deterministic commands for status, start, stop, flatten, daily lock, usable limit, PnL, trades, and journal.
- Use separate model and operator tokens.
- Validate gateway origin and refuse insecure non-loopback HTTP.
- Preserve quantity as gateway-owned.
- Describe 0.5% target as portfolio context, never trade geometry.
- Ship no scheduled worker until event input and learning evidence contracts exist.
- Verify distribution hashes and standard-library tests.

## Non-goals

- Autonomous event worker.
- Real venue credentials.
- Numerical probability models.
- Automatic lesson activation.
- Profitability claim.

## Acceptance

The paired profile must pass tests and operate against the GC-001 local API without possessing any exchange credential.
